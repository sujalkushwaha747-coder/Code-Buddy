# Demo Script

Use this script to record a short project demo.

## Recommended Length

- 2 to 4 minutes

## Demo Flow

### 1. Intro

Say:

`This is my AI Code Reviewer platform built with React, Express, Prisma, MySQL, JWT auth, GitHub OAuth, and LLM-powered code analysis.`

### 2. Authentication

Show:

- register page
- login page
- dashboard after login

### 3. Pasted Code Review

Show:

- open editor
- choose a language
- paste sample code
- click `Review Code`
- explain:
  - summary
  - categorized issues
  - scores
  - metrics
  - improved code

### 4. GitHub Repository Review

Show:

- click `Connect GitHub`
- open repositories page
- choose a repository
- browse files
- preview a file
- review the selected file

### 5. Review History

Show:

- saved reviews
- stored issues
- stored improved code
- repository metadata

### 6. Insights Dashboard

Show:

- total reviews
- score trends
- issue-type patterns
- language breakdown

### 7. Close

Say:

`This project demonstrates full-stack product architecture, secure auth, third-party integration, AI response handling, persistence, analytics, and a production-oriented React and Node workflow.`
